Voluntary Observing Ships (VOS) via WIS2/ICOADS

Discover marine observations available through Voluntary Observing Ships (VOS) via WIS2/ICOADS, including parameters, platforms, spatial and temporal coverage, metadata, and access methods.

Operator
WMO VOS / national meteorological services
Role
Operational network + historical archive
Platforms
Commercial/research ships
Observed variables
Wind; pressure; air temperature/humidity; SST; waves; weather/visibility/clouds
Spatial coverage
Global shipping routes
Period
Historical archive 1662-present via ICOADS; operational current via WIS2
Depth coverage
Surface/near-surface; sensor height metadata varies
QC and data mode
Operational QC + ICOADS archive QC

Subscribe/search WIS2 for current SHIP data; ingest ICOADS daily/monthly files for historical records
