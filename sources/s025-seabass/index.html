SeaBASS

Discover marine observations available through SeaBASS, including parameters, platforms, spatial and temporal coverage, metadata, and access methods.

Operator
NASA Ocean Biology Processing Group
Role
In-situ ocean color / bio-optical archive
Platforms
Ships; moorings; field campaigns; optical systems
Observed variables
Rrs/radiance; absorption/scattering/backscatter; pigments/chlorophyll; CTD; nutrients; fluorescence; productivity; plankton imagery; atmospheric optics
Spatial coverage
Global field campaigns
Period
Campaign-dependent; multi-decadal archive
Depth coverage
Surface and profile measurements; searchable by water depth; variable-dependent
QC and data mode
Submission/QC standards; validation-oriented
Access method
Use File Search, select products/date/bbox/depth, then Download All/Selection
