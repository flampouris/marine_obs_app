MARINE OBSERVATION SOURCE · S018

MEOP-CTD / MEOP-SMS / MEOP-TDR

Discover marine observations available through MEOP-CTD / MEOP-SMS / MEOP-TDR, including parameters, platforms, spatial and temporal coverage, metadata, and access methods.

Operator
MEOP consortium
Role
Animal-borne profile archive
Platforms
Instrumented marine mammals
Observed variables
Temperature; salinity; pressure/depth; high-density T/light in TDR; submesoscale CTD in SMS
Spatial coverage
Global high-latitudes, especially Southern Ocean and North Pacific/Atlantic
Period
2004-present for MEOP-CTD; database version dependent
Depth coverage
Surface to animal dive depth, often hundreds to >1000 m
QC and data mode
Quality-controlled adjusted profiles; QC/error fields
Access method
Download list_profiles/list_tags/list_deployments CSV; filter locally; then retrieve public NetCDF bundle
Indexed download targets
3

Canonical parameters

  • Practical salinity practical_salinity
  • Sea-water pressure sea_water_pressure
  • Sea-water temperature sea_water_temperature

Discovery and access

Very useful because metadata CSVs are already shaped like an existence index.
