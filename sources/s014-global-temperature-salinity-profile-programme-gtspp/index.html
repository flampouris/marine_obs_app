Global Temperature-Salinity Profile Programme (GTSPP)

Discover marine observations available through Global Temperature-Salinity Profile Programme (GTSPP), including parameters, platforms, spatial and temporal coverage, metadata, and access methods.

Operator
WMO/IOC / NOAA NCEI / DFO Canada
Role
Global T/S profile archive + real time
Platforms
CTD; XBT; Argo; ship and other profile platforms
Observed variables
Temperature; salinity profiles
Spatial coverage
Global
Period
1990-present in current query interface; archive contains older accessions
Depth coverage
Profile depths/pressures; can exceed 1000 m/full-depth depending instrument
QC and data mode
Real-time and best-copy/delayed QC
Access method
Use GTSPP Interface for spatial/time/type search; use HTTP/THREDDS for bulk or individual NetCDF
Indexed download targets
3

Canonical parameters

  • Practical salinity practical_salinity
  • Observation depth sample_depth
  • Sea-water temperature sea_water_temperature

Discovery and access

Strong source for operational and best-copy T/S profile discovery; overlaps Argo/WOD.
