MARINE OBSERVATION SOURCE · S013

World Ocean Database (WOD)

Discover marine observations available through World Ocean Database (WOD), including parameters, platforms, spatial and temporal coverage, metadata, and access methods.

Operator
NOAA NCEI / IODE
Role
Global profile archive / aggregator
Platforms
CTD; bottles/OSD; XBT/MBT; profiling floats; drifters; moored buoys; gliders; animal tags; surface-only and more
Observed variables
Temperature; salinity; oxygen; nutrients; chlorophyll; tracers; plankton and many other profile variables
Spatial coverage
Global
Period
1773-present
Depth coverage
Surface to full ocean depth; searchable by deepest measurement
QC and data mode
Uniform WOD QC; IQuOD flags/uncertainty options
Access method
Use WODselect to build query, choose format/depth-level/QC, submit email, then download generated files
Indexed download targets
13
